# ロボット規格ビューア

ゲームクリエイター甲子園2026 ロボット部門の出展作品「ロボット規格」の Web ビューアです。
インストール不要で、ブラウザだけで動きます。

開くと、動いているロボットが1体います。脚を押すと腰ごと別の脚に替わり、そのまま歩きます（歩き方は脚の長さから式で決まります）。体を押すと見た目（世界観）が替わります。形は1つも替えず、テクスチャだけを替えています。

作る人向けの画面（`?full`）：

- **見本を見る**：見本のロボットを回して見る。世界観（テクスチャ）を10種類から切り替えられる。
- **自分で組み立てる**：置き場のパーツを光っている接続口へドラッグしてつなぐ。形と大きさが両方合う口だけつながる。
- **テスト部屋**：重力と当たり判定のある部屋で、組んだロボットを歩かせたり技を出したりする。

企画書：https://docs.google.com/presentation/d/19mLz_kgfR3lWMdFyHlBK5YBztLL8zdGyVKlxP3l4Jt4/edit

## AI の使用について

- 規格のルール（接続口・正面・役割名・動きの決まり）は本人が決めたものです。
- パーツのうち26種の形とテクスチャは Tripo AI で生成しました（規格への合わせ込みは本人のルールによる）。審査対象外として申告しています。
- ビューアのコードは、本人の仕様と判断をもとに Claude が書きました。
